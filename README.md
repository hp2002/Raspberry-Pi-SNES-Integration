
# MarioKart
- Help Mario drive through the dangerous road and reach the castle!
- A 2d mario kart game coded in C for the raspberry pi 4. This was made according to the specifications mentioned in the A4 question. It was built on our solution of A3 for the SNES controller.

## Run Locally

To run this project locally, use the following command
```bash
  ./myProg
```
It will open the start menu. 


## Controls

- To select an option press A.
- To move the kart use the D pad controls.
- press start for pause menu




## Explaining the icons
- Clock icon: increases the time
- Banana icon: decreases life by 1
- plotholes icon: decreases life by 1
- movable objects: decreases life by 1
- heart icon: increases life by 1
- star icon: gives invincibility to kart against the enemies
- grey icon: road
- green icon: grass


## Player
- Mario (Red kart)

## Obstacles
- Banana Peel
- Potholes

## Enemy
- Bowser (Green kart)

## Value packs
- Extra life
- Power Star
- Extra time

## Artwork
The artwork used in the game were created on an iPad. Some of the
characters were created on a high resolution square and were condensed
to a 32x32 image. The start menu and the pause menu were also created 
on an iPad. All of the assets were converted to a .c file using GIMP.
